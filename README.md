# ブログ

パスワード付きの個人ブログです。記事は投稿画面の中で暗号化してからこのリポジトリに保存されるため，リポジトリ自体は公開で構いません（記事の本文・タイトル・画像はすべて暗号文です）。

- 閲覧：サイトを開いてパスワードを入力
- 投稿：右上の「書く」（初回だけ GitHub のアクセストークンを設定）
- 組版：JIS X 4051:2004 と W3C「日本語組版処理の要件」に従う（`assets/jlreq.js`）
- 数式：TeX（KaTeX），記法：Markdown＋ルビ `{漢字|かんじ}`・圏点 `《《強調》》`・注 `[^1]`

ビルドは不要です。GitHub Pages の公開元を「main ブランチの / (root)」にすれば動きます。
